# The Funniest Honest Appliance Error

A make.fun entry: a washing machine finally tells the truth about an
unbalanced spin cycle instead of hiding behind a cryptic error code.

The program writes one line to `/output/entry.txt`:

> UNBALANCED LOAD: I HAVE WALKED 4 INCHES ACROSS THE FLOOR TRYING TO SPIN ONE WET HOODIE. PLEASE REDISTRIBUTE.

## Run

```sh
python3 main.py
cat /output/entry.txt
```

Requires Python 3 (standard library only). The output directory is created
if missing.
